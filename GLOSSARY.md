# Математические игры

Термины для подготовки математических задач и приёма бумажных бланков.

## Термины

**Турнир**

Соревнование по решению математических задач.

**Задача**

Математическое задание, которое готовит составитель.

**Команда**

Группа учеников, у которой есть заранее присвоенный номер и свой комплект бланков ответов.

**Бланк**

Бумажный экземпляр с QR-кодом, на котором ученик записывает ответ.

**Приём бланка**

Регистрация отправки с фотографией бумажного бланка после проверки условий приёма.

**Срок окончания приёма**

Время, которое задаёт администратор при открытии приёма. С этого момента новые отправки считаются поздними.

**Множитель**

Коэффициент на бланке, который влияет на количество баллов за ответ.

**Представитель**

Участник оргкоманды, который фотографирует принесённые бланки и отправляет их на проверку.

**Ученик**

Участник команды, который решает задачи без аккаунта в системе.

**Составитель заданий**

Участник оргкоманды, который готовит задания для турнира.

**Проверяющий**

Участник жюри, который проверяет ответы учеников.
